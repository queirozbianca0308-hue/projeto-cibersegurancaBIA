# Projeto: Cibersegurança do Zero – Aprendendo a se Proteger

## 1. Apresentação
Este projeto tem como objetivo apresentar conceitos básicos de segurança da informação, utilizando Python como ferramenta de aprendizagem.

## 2. Objetivos
- Compreender o funcionamento de malwares.
- Conhecer o conceito de ransomware.
- Entender o que é um keylogger.
- Estudar formas de proteção de dados.
- Aprender boas práticas de segurança digital.

## 3. Conteúdos estudados

### Malware
Software desenvolvido para realizar atividades maliciosas em dispositivos.

### Ransomware
Tipo de malware que bloqueia ou criptografa arquivos e exige pagamento para tentar recuperar o acesso.

### Keylogger
Programa que registra teclas digitadas, podendo comprometer informações pessoais.

### Segurança da Informação
Conjunto de práticas utilizadas para proteger dados e sistemas contra ameaças digitais.

## 4. Como podemos nos proteger?
- Utilizar senhas fortes.
- Ativar a autenticação em duas etapas.
- Manter programas atualizados.
- Evitar links suspeitos.
- Utilizar ferramentas de segurança.
- Fazer cópias de segurança dos arquivos.

## 5. Conclusão
O estudo permitiu conhecer diferentes ameaças digitais e compreender a importância da segurança da informação e da proteção de dados.

**Observação:** Este repositório apresenta conteúdos teóricos estudados durante as aulas. Não representa a execução prática de um malware ou keylogger.
